l                loop length in bars (1 = one bar)

b                BPM                        { / }         loop start/end bars

Mouse: left click draws/selects; drag body moves, drag right edge resizes.
Right click deletes. Wheel scrolls pitches; Shift+wheel scrolls time;
Ctrl+wheel zooms. MIDI recording requires selected input + R + playback.

Any key closes help. MIDI export includes notes/program/volume, not audio.
Current project format: fixed 4/4 and one constant tempo.
